🔥 One-Time Firebase Setup

This game uses Firebase Realtime Database so players on different phones can sync. Free forever, takes ~2 min to set up.

1
Go to console.firebase.google.com → Sign in → Create project (name it anything, disable Analytics)
2
In left sidebar → Build → Realtime Database → Create database → choose any region → Start in test mode → Done
3
Copy the Database URL shown (looks like https://your-project-default-rtdb.firebaseio.com) and paste it below
Your URL is saved in your browser only. Firebase free tier = 100 simultaneous connections — plenty for game nights.
